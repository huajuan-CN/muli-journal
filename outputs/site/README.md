# 暮里 MULI — 本地博客初版

一个不依赖构建工具和后端的静态博客原型，视觉参考了作品集站常见的编辑式排版和大图网格。

## 启动

在 Finder 中双击 `start.command`，或在这个目录执行：

```bash
python3 server.py 8080
```

然后打开 <http://127.0.0.1:8080>。

也可以直接双击 `index.html`，但建议使用本地服务器，浏览器兼容性更稳定。

## 已实现

- 响应式作品网格、分类筛选、随机漫游
- 悬浮式弹出菜单
- 暗夜主题与半透明悬浮界面
- 本地后台：概览、文章管理、站点文字编辑、数据与发布
- 首页、区块标题、菜单、按钮、页脚和 SEO 文案可直接在后台修改
- Edge、Safari 等浏览器通过本机服务读取同一份站点配置与文章
- 文章阅读层与上一篇 / 下一篇
- 文章管理：查看、复制示例、编辑本地文章、两步确认删除
- 首页「ONE · 一个」RSS，包含本地代理与离线缓存
- 拖放或选择本地图片作为封面
- 文章和图片保存在浏览器 IndexedDB / localStorage
- 发布器草稿自动保存、实时预览
- 搜索、明暗主题、JSON 备份
- 全部示例封面均为本地 SVG，不依赖外部图片

## 说明

页面会优先连接本机后台服务，并把站点文字和本地文章保存到：

- `data/site-state.json`
- `media/`

如果服务没有启动，内容会临时保存在当前浏览器。不同浏览器之间如需立即刷新，可刷新页面或等待约 15 秒；也可以在后台“数据与发布”里手动上传或导入备份。

### 已有浏览器内容迁移

1. 关闭之前运行的终端服务，重新双击 `start.command`。
2. 在保存过内容的浏览器中重新加载页面。
3. 打开“后台 → 数据与发布”，确认“跨浏览器同步”显示已同步。
4. 在其他浏览器打开同一地址并刷新。

如果页面显示后台未连接，请先确认 `start.command` 仍在运行。也可以从原浏览器导出备份，再在新浏览器中导入。
